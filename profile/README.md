Small open-source tools and hardware experiments.

- [x500d-fido2](https://github.com/vinchlabs/x500d-fido2): turning an Alcatel X500D USB modem into a FIDO2 security key. Experimental, don't use it for real accounts yet.
- [rust-island-generator](https://github.com/vinchlabs/rust-island-generator): finite island worlds for Minecraft servers with Rust-style wipes.

Found a security issue? Please report it privately, see [SECURITY.md](https://github.com/vinchlabs/.github/blob/main/SECURITY.md).
